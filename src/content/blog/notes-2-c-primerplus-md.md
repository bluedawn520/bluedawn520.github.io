## main() 函数

```cpp
int main(void) {        // 函数头 —— 与调用函数的接口
    // 函数体 begin
    // statement
    return 0;           // 结束函数
    // 函数体 end
}
```

### 关键点

- `main()` 被**启动代码**调用，启动代码由编译器加到程序中，是程序和 OS 之间的桥梁
- C++ 中 `int main(void)` 和 `int main()` **等效**；C 中前者意味着对是否接收参数保持沉默
- ANSI/ISO C++ 标准允许 `main()` 后省略 `return 0;` —— 编译器到达末尾无返回语句时默认以 `return 0;` 结尾
- Windows 编程中可编写 DLL 模块，DLL 不是独立程序，不需要 `main()`
- 某些环境提供框架程序，调用非标准函数如 `_tmain()`，此时有隐藏的 `main()` 调用 `_tmain()`
- `main` **不是关键字**

## 注释

| 类型 | 格式 | 说明 |
|------|------|------|
| C++ 风格 | `// ...` | 推荐，不涉及符号匹配 |
| C 风格 | `/* ... */` | 需要正确匹配起始和末尾符号 |

> C99 标准在 C 中也添加了 `//` 注释。

## 预处理器

C/C++ 使用预处理器，在编译之前对源文件进行处理。

```cpp
#include <iostream>    // 将 iostream 文件内容添加到程序中
```

### 头文件类型

| 风格 | 约定 | 示例 | 说明 |
|------|------|------|------|
| C++ 旧式 | `.h` 结尾 | `iostream.h` | C++ 程序可用 |
| C 旧式 | `.h` 结尾 | `math.h` | C/C++ 程序可用 |
| C++ 新式 | 无扩展名 | `iostream` | C++ 程序可用，使用 `namespace std;` |
| 转换后的 C | 前缀 `c`，无扩展名 | `cmath` | C++ 程序可用，可使用 C 特性 |

## 命名空间（Namespace）

C++ 特性，旨在使编写大型程序及组合多厂商代码更容易。

- 类、函数、变量等标准组件放置在命名空间 `std` 中
- `cout` 实际上是 `std::cout`
- `endl` 实际上是 `std::endl`

```cpp
using namespace std;        // 使用 std 命名空间所有名称
using std::cout;            // 仅使用 std::cout
```

## cout 与 cin

- `cout` 是 `ostream` 类的对象实例
- `cin` 使用 `>>` 运算符从输入流中抽取字符
- **控制符（manipulator）**：如 `endl` 等对 `cout` 有特殊含义的符号
- **换行符**：C 风格 `\n`

## 类与对象

**类**描述了一种数据类型的全部属性（包括可对其执行的操作）。
**对象**是根据这些描述创建的实体。

C++ 发送消息的两种方式：
1. 使用类方法（类似函数调用）
2. 重新定义运算符（如 `cin`、`cout` 采用）

## 函数原型

在使用函数之前，C++ 编译器必须知道函数的**参数类型**和**返回值类型**。

```cpp
// 函数原型语句
int func(int a, int b);

// 省略分号则编译器解释为函数头，要求提供函数体
// C/C++ 将库函数的原型和定义分开：
// - 库文件包含函数的编译代码
// - 头文件包含原型
```

> C++ **不能在函数内嵌套定义函数**。

## 标记与空白

- **标记（token）**：一行代码中不可分割的元素
- **空白（white space）**：空格、制表符、回车

> 通常必须使用空白将两个标记分开；括号、逗号等字符是不需要空白分开的标记。
