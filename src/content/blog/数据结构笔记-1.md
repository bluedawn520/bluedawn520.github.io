## 1.1 线性表的类型定义

**线性表**：n 个数据元素的有限序列。

- **记录**：由若干数据项组成的数据元素
- **文件**：含有大量记录的线性表
- **位序**：元素 $a_i$ 是第 i 个元素，则 i 为其位序

### 特点

同一线性表中的元素属于同一数据对象，相邻元素之间具有**序偶关系**。除第一个外均有直接前驱，除最后一个外均有直接后继。

## 1.2 线性表的顺序表示和实现

### 顺序存储结构

用一段**地址连续**的存储单元依次存储数据元素。

第 $i$ 个元素的地址：

$$Loc(a_i) = Loc(a_1) + (i-1) \times l$$

其中 $Loc(a_1)$ 是基地址，$l$ 是单个元素所占存储单元。

### 顺序表动态分配

```cpp
#define LIST_INIT_SIZE  100     // 初始分配量
#define LISTINCREMENT   10      // 分配增量

typedef struct {
    ElemType *elem;     // 存储空间基址
    int length;         // 当前长度
    int listsize;       // 当前分配的存储容量
} SqList;
```

### 基本操作时间复杂度

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 按位查找 | $O(1)$ | 随机存取 |
| 插入 | $O(n)$ | 平均移动 $n/2$ 个元素 |
| 删除 | $O(n)$ | 平均移动 $(n-1)/2$ 个元素 |

### 有序表归并

```cpp
void MergeList_Sq(SqList La, SqList Lb, SqList &Lc) {
    // 已知 La、Lb 按值非递减排列
    // 归并后 Lc 也按值非递减排列
    pa = La.elem; pb = Lb.elem;
    Lc.listsize = Lc.length = La.length + Lb.length;
    pc = Lc.elem = (ElemType*)malloc(Lc.listsize * sizeof(ElemType));
    if (!Lc.elem) exit(OVERFLOW);
    pa_last = La.elem + La.length - 1;
    pb_last = Lb.elem + Lb.length - 1;
    while (pa <= pa_last && pb <= pb_last) {
        if (*pa <= *pb) *pc++ = *pa++;
        else *pc++ = *pb++;
    }
    while (pa <= pa_last) *pc++ = *pa++;
    while (pb <= pb_last) *pc++ = *pb++;
}
```

> 时间复杂度：$O(La.length + Lb.length)$，空间复杂度：$O(La.length + Lb.length)$

## 1.3 线性表的链式表示和实现

### 单链表

```cpp
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

| 特性 | 说明 |
|------|------|
| 头指针 | 指向第一个结点 |
| 空表（无头结点）| `L == NULL` |
| 空表（有头结点）| `L->next == NULL` |
| 存取方式 | 必须从头指针开始，**非随机存取** |

### 单链表基本操作

| 操作 | 时间复杂度 |
|------|-----------|
| 按位查找 | $O(n)$ |
| 插入 | $O(n)$（查找 $O(n)$ + 插入 $O(1)$）|
| 删除 | $O(n)$（查找 $O(n)$ + 删除 $O(1)$）|
| 头插法建立 | $O(n)$ |
| 尾插法建立 | $O(n)$ |

### 单链表归并（原地）

```cpp
void MergeList_L(LinkList &La, LinkList &Lb, LinkList &Lc) {
    pa = La->next; pb = Lb->next;
    Lc = pc = La;           // 用 La 的头结点作为 Lc 的头结点
    while (pa && pb) {
        if (pa->data <= pb->data) {
            pc->next = pa; pc = pa; pa = pa->next;
        } else {
            pc->next = pb; pc = pb; pb = pb->next;
        }
    }
    pc->next = pa ? pa : pb;
    free(Lb);               // 释放 Lb 的头结点
}
```

> 时间复杂度：$O(La.length + Lb.length)$，空间复杂度：$O(1)$（不新建结点）

### 静态链表

用数组描述的链表，游标（cur）代替指针。

```cpp
#define MAXSIZE 100

typedef struct {
    ElemType data;
    int cur;            // 游标（cursor）
} component, SLinkList[MAXSIZE];
```

> 需要预先分配较大空间，但插入删除无需移动元素。

### 循环链表

- 最后一个结点的指针域指向**头结点**，形成环
- 循环条件：`p != L` 或 `p->next != L`（而非 `p != NULL`）
- 有时设**尾指针**而非头指针，可简化某些操作（如合并两个表只需 $O(1)$）

### 双向链表

```cpp
typedef struct DuLNode {
    ElemType data;
    struct DuLNode *prior;
    struct DuLNode *next;
} DuLNode, *DuLinkList;
```

双向循环链表：`d->next->prior == d->prior->next == d`

| 操作 | 时间复杂度 |
|------|-----------|
| 插入 | $O(n)$（查找）|
| 删除 | $O(n)$（查找）|

## 1.4 顺序表 vs 链表

| 特性 | 顺序表 | 链表 |
|------|--------|------|
| 存储密度 | 高（只存数据）| 低（需额外指针域）|
| 随机存取 | ✓ 支持 | ✗ 不支持 |
| 插入删除 | 需移动大量元素 | 只需修改指针 |
| 扩展性 | 需预分配，可能浪费或溢出 | 动态分配，灵活 |
| 适用场景 | 查询多、修改少 | 插入删除频繁 |
