本文对 GSAT+walk 算法进行了两方面的改进：
1. **去除 GSAT 部分的"平移"操作**
2. **对每个子句进行赋权，并在搜索过程中动态调整子句权重**

---

## 1. 基础算法回顾

### 1.1 GSAT 伪代码

```plain
begin
    for i = 1 : MAX_TRIES
        T = random generate a true assignment
        for j = 1 : MAX_FLIPS
            if T satisfied then return T
            p = 翻转之后使满足子句的个数增加最多的那个变量
                若有多个则随机从中选一个
            T = the assignment after flipping p
        end for
    end for
    return "no solution found"
end
```

### 1.2 GSAT + Walk

在 GSAT 基础上引入**随机游走策略**：选择翻转变量时，以概率 $p$ 在不满足子句中随机选择一个变量翻转，以概率 $1-p$ 按照 GSAT 策略翻转。允许翻转后的目标值比当前差（适当后退，防止陷入局部最优）。

### 1.3 WalkSAT

在 Random Walk 上做了改变：选择变量时，**首先随机选择一个不满足子句 $c$**，将翻转变量限制在该子句中。

记变量翻转后由满足变为不满足的子句个数为 **break-count**：
- 若 break-count = 0，则翻转该变量
- 否则，以噪声概率 $p$ 在子句 $c$ 中随机选择一个变量
- 以 $1-p$ 在子句 $c$ 中选择 break-count 最小的变量

> WalkSAT 考虑了变量翻转后满足子句变为不满足的个数，尽可能使其降低，只关注了降低"变坏"的风险。

### 1.4 TSAT

在搜索过程中维持一个固定长度的**禁忌表**，记录翻转过的变量，每翻转一个变量就更新一次。防止一段时间之内反复翻转同一个位置，避免陷入局部极小，保证变量在搜索空间的均匀分布。

---

## 2. 本文的改进

### 2.1 去掉 GSAT+Walk 的"平移"操作

在**不加权的 GSAT** 中，"平台"（plateau）大量存在——搜索过程中目标函数值保持不变的情况。搜索过程往往需要经过多次**平移**（sideway move，目标函数值不变但解发生变化的移动）通过平台，才能使不满足子句个数进一步减少。因此在不加权的 GSAT 中，平移是必需的，并且占了大部分移动。

在 **GSAT+Walk** 中，随机行走允许"上移"（目标函数值增加），因此随机游走策略使得搜索过程不会陷入某一平台或局部极小点。但平移依旧存在，并且约占所有移动的一半。

**关键发现**：通过大量实验证实，GSAT 部分的平移不再是必需的，去掉平移后算法效率反而提高了。

### 2.2 子句动态赋权

除了去除平移操作外，本文还对每个子句进行赋权，并在搜索过程中**动态调整子句权重**，以引导搜索过程更有效地探索解空间。

---

## 3. 改进后的算法

去掉 GSAT 部分平移后的 GSAT+Walk 算法框架：

```plain
随机产生一个真值指派作为搜索的起点
while 在当前指派下还有不满足的子句 do
    产生一个 [0,1) 范围内的随机数 r
    if r < p then
        随机选择一个不满足子句，从中随机选择一个变量翻转
    else
        在不满足子句中选择使 break-count 最小的变量翻转
        （若 break-count = 0 则必选；若有多个则随机选择）
    end if
end while
return 当前真值指派
```
