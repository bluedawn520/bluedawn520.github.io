## 三种编程范式

C++ 融合了三种编程方式：

| 范式 | 代表 | 核心思想 |
|------|------|---------|
| **过程性编程** | C 语言 | 强调算法，确定计算机应采取的措施 |
| **面向对象编程** | C++ 类 | 强调数据，设计与问题本质特性相对应的数据格式 |
| **泛型编程** | C++ 模板 | 独立于特定数据类型，提供执行常见任务的工具 |

## 核心概念

- 计算机处理的两个基本概念：**数据**（程序使用及处理的信息）+ **算法**（程序使用的方法）

### 过程性编程

- 首先确定计算机应采取的措施，然后使用编程语言实现这些操作
- 强调编程的**算法方面**
- 早期语言（FORTRAN、BASIC）遇到组织问题 → "意大利面式编程"

### 结构化编程

将分支限制为一小组行为良好的结构：
- `for` 循环
- `while` 循环
- `do…while` 循环

### 自顶向下设计（Top-down）

- 将大型程序分解为小型、便于管理的任务
- 一直分解到小型、便于编程的模块
- 鼓励开发**函数**来表示各个程序模块

### 面向对象编程（OOP）

- **理念**：设计与问题本质特性相对应的数据格式
- **类**：描述数据格式的规范
- **对象**：根据规范构造的特定数据结构
- **方法**：先设计类，再设计使用这些对象的程序
- **自下而上（Bottom-up）**：从低级组织（类）到高级组织（程序）

OOP 的核心特性：
- 将数据和方法合并为类定义
- **可重用代码**
- **信息隐藏**保护数据
- **多态**为运算符创建多个定义
- **继承**使旧类派生出新类

### 泛型编程（Generic Programming）

- 目标与 OOP 相同：使重用代码和抽象通用概念更简单
- OOP 强调**数据方面**
- 泛型编程强调**独立于特定数据类型**
- OOP 是管理大型项目的工具
- 泛型编程提供执行常见任务的工具

### C++ 的二重性

| 方面 | 能力 |
|------|------|
| OOP 部分 | 高级抽象，将问题设计概念相联系 |
| C 部分 | 紧密联系硬件 |

## 程序构建流程

```
源代码 → 编译器 → 目标代码 → 链接程序（+ 启动代码 + 库代码）→ 可执行代码
```
