本文从解空间的角度出发分析了交叉算子的作用，针对其盲目搜索的缺陷，提出了一种通过控制交叉子代的落点位置，使得交叉子代大概率地朝最优解方向前进的有向交叉策略。

## 传统交叉算子的局限

传统交叉算子在解空间中**随机选择落点**，缺乏对解空间结构的利用。子代的产生方向完全随机，无法保证朝着更优区域进化。

## 有向交叉策略

有向交叉通过分析父代个体的差异，**引导交叉子代朝向更优区域移动**。

### 决策逻辑

对于 SAT 问题，记个体为 $x$，翻转后表示可满足子句的增加数为 $diff(x_i)$。有向交叉的决策逻辑如下：

```c
for each i:
    if (x_i == y_i) {
        if (diff(x_i) > 0) {
            flip        // 可通过概率 p 实现跳出局部最优
        } else {
            not flip
        }
    } else {
        if (x_i > y_i) {
            if (x_i > 0) {
                flip      // 可通过概率 p 实现跳出局部最优
            } else {
                not flip
            }
        } else {
            if (x_i > 0) {
                flip      // 可通过概率 p 实现跳出局部最优
            } else {
                not flip
            }
        }
    }
}
```

### 核心思想

根据变量翻转后对可满足子句数的影响（$diff$ 值），**有方向地决定是否翻转**，从而引导子代向更优解区域收敛。其中引入概率 $p$ 是为了保留一定的随机性，使算法具备跳出局部最优的能力。

### 与传统交叉的对比

| 特性 | 传统交叉 | 有向交叉 |
|------|---------|---------|
| 子代落点 | 随机 | 朝向更优方向 |
| 解空间利用 | 无 | 利用 $diff$ 值引导 |
| 局部最优逃逸 | 依赖变异 | 概率 $p$ 保留随机性 |
| 收敛效率 | 较低 | 较高 |
