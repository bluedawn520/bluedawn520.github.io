## A 开头短语

| 短语 | 释义 |
|------|------|
| a bit | 稍微，有点 |
| a body of | 大量，大批（信息、知识等） |
| a case in point | 恰当的例子，例证 |
| a chance of lifetime | 千载难逢的机会 |
| a copy of | 一本，一份 |
| a couple of | 一双，一对；几个 |
| a fraction of | 一小部分 |
| a handful of | 一小撮 |
| a host of | 许多，一大群 |
| a large number of | 大量的（+ 可数名词） |
| a large quantity of | 大量的（+ 可/不可数名词） |
| a matter of | （关于）问题 |
| a multitude of | 许多，大量 |
| a number of | 若干 |
| a passing fad | 流行一时 |
| a range of | 一系列 |
| a wide range of | 范围广的，多方面的 |
| a sea of | 一大片 |
| a sequence of | 一连串 |
| a series of | 接连发生的 |
| a string of | 一连串 |
| a sum of | 一笔，一定数量 |
| a swarm of | 一大群 |
| a ton of | 许多，大量 |
| a variety of | 各种各样的 |
| a/the majority of | 大多数的，大部分 |
| abandon oneself to | 沉溺于 |
| abide by | 恪守，遵守 |
