> 基于严蔚敏《数据结构》（C 语言版）整理。

数据结构是一门研究**非数值计算**的程序中计算机的**操作对象**以及它们之间的**关系和操作**的学科。

---

## 0.1 基本术语

| 术语 | 定义 |
|------|------|
| **数据** | 能输入到计算机中并被计算机程序处理的符号总称 |
| **数据元素** | 数据的基本单位，可由若干数据项组成 |
| **数据项** | 数据的不可分割的最小单位 |
| **数据对象** | 性质相同的数据元素的集合，是数据的一个子集 |
| **数据结构** | 相互之间存在一种或多种特定关系的数据元素的集合 |

### 数据结构的形式定义

二元组 **(D, S)**：
- D：数据元素的有限集
- S：D 上关系的有限集

### 逻辑结构

| 类型 | 特点 |
|------|------|
| **集合** | 元素之间无特定关系 |
| **线性结构** | 元素之间一对一 |
| **树形结构** | 元素之间一对多 |
| **图状/网状结构** | 元素之间多对多 |

### 存储结构（物理结构）

| 类型 | 实现方式 | 特点 |
|------|---------|------|
| **顺序存储** | 元素在存储器中的相对位置 | 随机存取 |
| **链式存储** | 指针指示元素存储地址 | 非随机存取 |

### 数据类型

- **原子类型**：值不可分解（整型、实型、字符型、枚举型、指针型、空类型）
- **结构类型**：值由若干成分按某种结构组成（数组）

### 抽象数据类型（ADT）

一个数学模型以及定义在该模型上的一组操作。

- 定义只取决于逻辑特性，与内部表示和实现无关
- 整型是特殊的 ADT（不同处理机实现不同，但数学特性相同）
- 由三元组 **(D, S, P)** 表示：D 是数据对象，S 是关系集，P 是基本操作集

| ADT 类型 | 说明 |
|---------|------|
| 原子类型 | 变量值不可分解 |
| 固定聚合类型 | 值由确定数目成分按结构组成 |
| 可变聚合类型 | 成分数目不确定 |

## 0.2 ADT 的表示和实现

### 预定义常量和类型

```cpp
#define TRUE        1
#define FALSE       0
#define OK          1
#define ERROR       0
#define INFEASIBLE  -1
#define OVERFLOW    -2

typedef int Status;
```

### ADT 格式

```plain
ADT 抽象数据类型名 {
    数据对象：〈数据对象的定义〉
    数据关系：〈数据关系的定义〉
    基本操作：〈基本操作的定义〉
} ADT 抽象数据类型名
```

### 基本操作定义格式

```plain
基本操作名(参数表)
    初始条件：〈初始条件描述〉
    操作结果：〈操作结果描述〉
```

### 参数类型

- **赋值参数**：只为操作提供输入值
- **引用参数**（`&` 开头）：除输入外还将返回操作结果

## 0.3 算法与复杂度

### 时间复杂度

以问题的**基本操作重复执行的次数**作为时间度量。

### 空间复杂度

- 若输入数据空间只取决于问题本身 → 只需分析额外空间
- 若额外空间是常数 → **原地工作**
- 若依赖特定输入 → 一般考虑**最坏情况**

## 0.4 三元组 Triplet 的实现示例

```cpp
// 动态分配的顺序存储结构
typedef ElemType *Triplet;

// 基本操作
Status InitTriplet(Triplet &T, ElemType v1, ElemType v2, ElemType v3);
Status DestroyTriplet(Triplet &T);
Status Get(Triplet T, int i, ElemType &e);      // 用 e 返回第 i 元
Status Put(Triplet &T, int i, ElemType e);      // 改变第 i 元为 e
Status IsAscending(Triplet T);                   // 升序返回 1
Status IsDescending(Triplet T);                  // 降序返回 1
Status Max(Triplet T, ElemType &e);              // 最大值
Status Min(Triplet T, ElemType &e);              // 最小值
```

> `malloc()` 用于动态内存分配；`free()` 释放内存；`OVERFLOW` 表示分配失败。
